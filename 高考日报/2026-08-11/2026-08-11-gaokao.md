## 数学

### 讲解

已知数列 $\{a_n\}$ 的前 $n$ 项和 $S_n$，求通项 $a_n$ 是高考常考题型。核心关系为：

$$
a_n = \begin{cases}
S_1, & n=1 \\
S_n - S_{n-1}, & n \ge 2
\end{cases}
$$

**关键点**：$S_n - S_{n-1}$ 只能表示 $n \ge 2$ 时的 $a_n$，不能直接用于 $n=1$。必须先求 $a_1 = S_1$，再求 $n \ge 2$ 时的表达式，最后验证 $n=1$ 时是否满足该表达式。若满足，可合并为一个通项；若不满足，必须写成分段函数形式。

### 例题

已知数列 $\{a_n\}$ 的前 $n$ 项和 $S_n = n^2 + n + 1$，求数列 $\{a_n\}$ 的通项公式。

### 答案

$$
a_n = \begin{cases}
3, & n=1 \\
2n, & n \ge 2
\end{cases}
$$

### 解析

1. 当 $n=1$ 时，$a_1 = S_1 = 1^2 + 1 + 1 = 3$。
2. 当 $n \ge 2$ 时，
   $$
   a_n = S_n - S_{n-1} = (n^2 + n + 1) - [(n-1)^2 + (n-1) + 1]
   $$
   化简：
   $$
   a_n = n^2 + n + 1 - (n^2 - n + 1) = 2n
   $$
3. 验证 $n=1$：将 $n=1$ 代入 $2n$ 得 $2$，而 $a_1 = 3$，不相等，所以不能合并。

因此通项公式必须分段表示。

### 易错提醒

**不要直接写 $a_n = S_n - S_{n-1}$ 就完事**。很多同学忽略 $n=1$ 的单独验证，导致漏掉分段。注意：只有当 $S_n$ 的常数项为 $0$ 时（即 $S_n$ 是 $n$ 的齐次式），$a_n = S_n - S_{n-1}$ 的结果才恰好对 $n=1$ 也成立；若 $S_n$ 含有非零常数项，则 $n=1$ 时一定不满足，必须分段。

## 语文

### 讲解

**文言文翻译：词类活用之“意动用法”与“使动用法”**

在文言文翻译中，词类活用是高频考点，其中“意动用法”和“使动用法”是学生最容易混淆的两大类型。二者在形式上都是“动词+宾语”或“形容词+宾语”，但语义逻辑截然不同。

- **使动用法**：主语使宾语**发出**谓语动词所表示的动作或**具有**该性质。翻译为“使……（怎么样）”。强调的是**客观结果**，即动作或状态确实发生了改变。
- **意动用法**：主语**主观上认为**宾语怎么样，或**把宾语当作**什么。翻译为“认为……怎么样”或“把……当作……”。强调的是**主观看法**，客观事实未必如此。

**判断技巧**：代入“使”和“认为”分别翻译，看哪个更符合语境。若动作是主语强加给宾语、宾语被动接受的，则是使动；若只是主语内心的想法、评价，则是意动。

### 例题

翻译下列句子，并指出加点词的活用类型。

**“渔人甚异之，复前行，欲穷其林。”**（陶渊明《桃花源记》）

（“异”字加点）

### 答案

翻译：渔人对此感到非常惊异，又继续往前走，想要走到那片林子的尽头。

“异”为**意动用法**，意为“以……为异”，即“认为……奇异”。

### 解析

1. **定位活用词**：“异”本为形容词，意为“奇异、不同”。此处“异之”中，“之”指代前文所见景象（桃花林夹岸数百步等）。
2. **代入判断**：若译为“使……奇异”，即“渔人使桃花林奇异”，逻辑不通，桃花林本身奇异，并非渔人使它奇异。若译为“认为……奇异”，即“渔人认为桃花林奇异”，符合渔人初见桃花林的惊讶心理，逻辑通顺。
3. **确认类型**：因此，“异”是形容词的意动用法，表示主语（渔人）的主观感受。
4. **落实翻译**：翻译时需将“异”的意动含义明确译出，即“以……为异”或“认为……奇异”，不能直译为“奇异”。

### 易错提醒

**切勿将“意动”误判为“使动”**。判断标准是看动作是“主观认为”还是“客观使令”。例如“孔子登东山而小鲁”（《孟子》），若译为“使鲁国变小”则荒谬，正确应为“认为鲁国变小”。做题时，先代入“使”翻译，若不合逻辑或情理，再代入“认为”，往往能快速锁定答案。

## 英语

### 讲解：if条件句中的虚拟语气（含混合虚拟）

虚拟语气用于表达与事实相反的假设或难以实现的愿望。在 if 条件句中，动词形式需根据「假设的时间」发生相应变化，这是高考语法填空和短文改错的高频考点。

**基本形式（三大类）：**

| 假设时间 | if 从句谓语 | 主句谓语 |
|---------|------------|---------|
| 与现在事实相反 | did / were | would / could / might / should + do |
| 与过去事实相反 | had done | would / could / might / should + have done |
| 与将来事实相反 | were to do / should do / did | would / could / might / should + do |

**混合虚拟（重点、易错）：**
当从句与主句所指时间不一致时，各自按实际时间选用对应形式。例如：从句指过去（用 had done），主句指现在（用 would + do）。

**if 省略倒装：**
当从句含有 were、had 或 should 时，可省略 if，将这些词提前至主语前。例如：
- If I were you → **Were I you**
- If I had known → **Had I known**
- If it should rain → **Should it rain**

### 例题

If you ______ (follow) my advice at that time, you wouldn't be in such trouble now.

### 答案

had followed

### 解析

1. **判断时间**：从句中有时间状语 `at that time`，指过去；主句中有 `now`，指现在。因此这是一个**混合虚拟条件句**。
2. **确定从句形式**：从句与过去事实相反（事实是：你当时没有听我的建议），所以用 `had + 过去分词`，即 **had followed**。
3. **确定主句形式**：主句与现在事实相反（事实是：你现在陷入了麻烦），所以用 `would + 动词原形`，即 `wouldn't be`。
4. **整句翻译**：如果你当时听了我的建议，你现在就不会陷入这样的麻烦。

### 易错提醒

看到主句是 `wouldn't be`（现在时形式），很多同学会误以为从句也应对应现在时间，从而误填 `followed` 或 `were to follow`。**判断虚拟语气时，务必先找时间状语**（如 `at that time`、`now`、`yesterday`、`today`），主从句时间可能不一致，不能机械地只看主句形式。另外，若从句省略 if 进行倒装，否定词 not 不能提前，如 `Had I not seen it`（不可写成 `Hadn't I seen it`）。

## 物理

### 讲解：斜面体与地面间摩擦力的判断（整体法与隔离法）

在力学综合题中，常出现“物块在斜面体上运动，求斜面体与地面之间的摩擦力”这类问题。许多同学习惯性地只隔离物块分析，导致漏解或错解。核心方法是**先整体、后隔离**：

1. **整体法**：将物块和斜面体视为一个系统。若系统所受外力在水平方向合力为零，则地面对斜面体的摩擦力为零；若系统有水平方向的加速度分量，则地面对斜面体的摩擦力提供该加速度，大小为 \( f = (M+m)a_x \)。
2. **隔离法**：当整体法不易判断时，隔离斜面体，分析物块对斜面体的压力 \( N \) 和摩擦力 \( f_{\text{物}} \)，再求这两个力水平分量的合力，即为地面对斜面体的摩擦力。

**关键结论**：
- 物块**匀速**下滑时，系统水平方向无加速度，地面对斜面体摩擦力为 **0**。
- 物块**加速**下滑时，系统有水平加速度分量，地面对斜面体摩擦力**不为 0**，方向与加速度水平分量方向相同。
- 物块**减速**下滑时，同理，摩擦力方向与加速度水平分量方向相同。

---

### 例题

如图所示，质量为 \( M \) 的斜面体静止在粗糙水平地面上，倾角为 \( \theta \)。质量为 \( m \) 的物块恰能沿斜面匀速下滑。现对物块施加一个竖直向下的恒力 \( F \)，物块仍沿斜面下滑。则施加力 \( F \) 后，地面对斜面体的摩擦力为（ ）

A. 大小为 \( (mg+F)\sin\theta\cos\theta \)，方向水平向左  
B. 大小为 \( (mg+F)\sin\theta\cos\theta \)，方向水平向右  
C. 大小为 0  
D. 无法判断  

---

### 答案

**C**

---

### 解析

**第一步：分析施加力 \( F \) 前的状态**

物块恰能沿斜面匀速下滑，说明物块受力平衡。沿斜面方向有：

\[
mg\sin\theta = \mu mg\cos\theta
\]

因此：

\[
\mu = \tan\theta
\]

**第二步：分析施加力 \( F \) 后的状态**

施加竖直向下的恒力 \( F \) 后，物块受到重力 \( mg \)、推力 \( F \)、支持力 \( N \) 和滑动摩擦力 \( f \)。

沿斜面方向：

\[
(mg+F)\sin\theta - \mu (mg+F)\cos\theta = (mg+F)(\sin\theta - \mu\cos\theta)
\]

由于 \( \mu = \tan\theta \)，所以：

\[
\sin\theta - \mu\cos\theta = \sin\theta - \tan\theta\cos\theta = \sin\theta - \sin\theta = 0
\]

因此物块仍沿斜面**匀速下滑**，加速度为零。

**第三步：整体法判断摩擦力**

将物块和斜面体视为整体。系统在水平方向没有加速度（物块匀速，斜面体静止），所以水平方向合力为零。地面对斜面体的摩擦力必须为 0。

---

### 易错提醒

**易错点**：误认为施加竖直向下的力 \( F \) 后，物块对斜面的压力增大，摩擦力也增大，从而认为地面对斜面体有摩擦力。

**正确理解**：滑动摩擦力 \( f = \mu N \) 与压力成正比，但物块沿斜面方向的重力分量也同步增大。由于 \( \mu = \tan\theta \)，两者始终相等，物块仍匀速下滑，系统水平方向无加速度，地面对斜面体摩擦力依然为零。

**特别提醒**：只有当物块**加速**或**减速**下滑时，地面对斜面体的摩擦力才不为零。若物块匀速下滑，无论是否施加额外力（只要不改变匀速状态），地面对斜面体的摩擦力始终为零。

## 化学

### 讲解：歧化反应与归中反应中的电子转移计算

氧化还原反应中，电子转移数的计算是高考高频考点，而**歧化反应**与**归中反应**是其中最易混淆的两类特殊反应。

- **歧化反应**：同一物质中同种元素，在反应中一部分化合价升高，另一部分化合价降低。例如：`Cl₂ + 2NaOH → NaCl + NaClO + H₂O`。氯元素从 0 价分别变为 -1 价和 +1 价。
- **归中反应**：不同物质中同种元素（通常化合价不同），在反应中向中间价态靠拢。例如：`2H₂S + SO₂ → 3S↓ + 2H₂O`。硫元素从 -2 价和 +4 价均变为 0 价。

**电子转移数计算核心原则**：**只算“升”或只算“降”**，不能把升高和降低的数目相加。因为氧化还原反应中，氧化剂得到的电子总数 = 还原剂失去的电子总数。

### 例题

**题目**：在反应 `3Cl₂ + 6KOH → 5KCl + KClO₃ + 3H₂O` 中，若消耗 3 mol Cl₂，则转移电子的物质的量为多少？

### 答案

转移电子的物质的量为 **5 mol**。

### 解析

1. **标化合价，找变化**：
   - 反应前：Cl₂ 中氯元素为 0 价。
   - 反应后：KCl 中氯为 -1 价（降低），KClO₃ 中氯为 +5 价（升高）。

2. **判断产物来源与比例**：
   - 5 个 Cl 原子从 0 价降到 -1 价，共得 5 个电子。
   - 1 个 Cl 原子从 0 价升到 +5 价，共失 5 个电子。
   - 得失电子守恒，符合“3Cl₂”中 6 个 Cl 原子的分配（5 + 1 = 6）。

3. **计算电子转移数**：
   - 根据“只算升或只算降”原则，取升高部分：1 mol Cl 原子升高 5 价，失去 5 mol 电子。
   - 因此，3 mol Cl₂ 参加反应时，转移电子数为 **5 mol**。

### 易错提醒

很多同学会误算为 6 mol，错误地把 5 个 Cl 得 5 mol 电子和 1 个 Cl 失 5 mol 电子相加（5 + 5 = 10），或者误以为 3 mol Cl₂ 全部变价、每个 Cl 转移 1 mol 电子（3 × 2 = 6）。**切记：转移电子数 = 氧化剂得电子数 = 还原剂失电子数，二者只能取其一，绝不能相加。** 判断时先找出化合价升高的那一种产物，用它计算最稳妥。

## 地理

### 讲解

**热力环流**是大气运动最简单的形式，也是高考常考的核心原理。其形成过程可概括为：

1. **地面冷热不均**（根本原因）→ 空气垂直运动：热处膨胀上升，冷处收缩下沉。
2. **同一水平面气压差**：近地面，热处因空气上升形成**低压**，冷处因空气下沉形成**高压**；高空与近地面气压性质**相反**。
3. **空气水平运动**：风从高压吹向低压，形成闭合环流。

**等压面弯曲规律**（核心考点）：
- 同一水平面上，**高压处等压面向上凸**，**低压处等压面向下凹**。
- 高空与近地面等压面弯曲方向**相反**。
- 注意：垂直方向上，海拔越高气压越低；比较气压高低必须先说明是否在同一水平面。

常见应用：海陆风、山谷风、城市热岛效应等，本质都是热力环流。

### 例题

读“某地热力环流示意图”，已知近地面甲地上空等压面向上凸，乙地上空等压面向下凹。据此判断下列说法正确的是（ ）

A. 甲地近地面为高压，气温高  
B. 乙地近地面为低压，气温低  
C. 甲地气流上升，乙地气流下沉  
D. 近地面风从甲地吹向乙地  

### 答案

C

### 解析

- 甲地上空等压面向上凸，说明甲地上空为**高压**，则近地面甲地为**低压**（气流上升，气温高）→ A错。
- 乙地上空等压面向下凹，说明乙地上空为**低压**，则近地面乙地为**高压**（气流下沉，气温低）→ B错。
- 近地面甲地为低压（上升气流），乙地为高压（下沉气流）→ C正确。
- 近地面风从高压乙地吹向低压甲地，即从乙地吹向甲地 → D错。

### 易错提醒

**不要混淆“高空等压面弯曲”与“近地面气压性质”**。等压面向上凸表示该处为高压，但若是在高空，则对应近地面为低压。判断时务必先明确是“近地面”还是“高空”，再结合垂直气流方向推理冷热状况。另外，气温高气压低只适用于**近地面**，高空相反，切勿直接套用。
