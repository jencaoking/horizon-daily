# 华为云 AI Shell

## 定位
华为云开发者空间里的免费云端 Linux 容器环境：打开浏览器就有 4 核 7G 服务器，内置大模型可直接对话。入口：developer.huaweicloud.com 侧边栏。

## 关键能力
- 配置：4 核 CPU（2.9GHz）、7.2G 内存、136G 磁盘、aarch64（ARM）架构
- 内置模型：GLM-5.1 + DeepSeek-V3.1，`Ctrl+P` 切换；每账号 **100W 免费 Token**；可配置第三方 API Key（相当于"模型容器"）
- AI 对话模式 → `Ctrl+C` ×2 切回普通 Linux 终端
- 内置 7 个华为云 Skills（计算/网络/存储/数据库/监控/IAM/Terraform）：自然语言直接操作云资源，如"查账户余额"（查询类免费）、"创建 2核4G 云服务器"（先生成 Terraform 配置再执行）
- 适用场景：临时开发机（跑 Python、编译、测试环境）、免费模型入口

## 价格 / 限制
- 免费；需要华为云账号 + 实名认证，账号不能欠费
- **6 小时有效期**，到期自动销毁，可手动延期；社区有油猴脚本每 2 小时自动延期保活
- 单账号同时最多开 3 个 Shell
- ARM 架构，部分 x86 专属软件装不了
- 单轮对话偶尔限流（提示"请求次数超了"，回复「继续」即可）
