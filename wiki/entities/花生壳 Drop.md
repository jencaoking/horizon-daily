# 花生壳 Drop

## 定位
贝锐花生壳的静态文件托管服务：把 HTML、ZIP 或整个网页文件夹拖进去，生成公网预览地址，免费、长期保存。

## 关键能力
- 操作方式与 Cloudflare Drop 几乎一样，且更简化：**可直接上传单个 html 文件**（Cloudflare 必须文件夹或压缩包）
- 所有托管域名**已在国内备案**：直接访问、微信内分享无限制
- 支持复杂静态前端：含 js 脚本、css 样式、3D 动画的页面实测丝滑
- 上传完成后登录花生壳账号认领，域名永久保存
- 完整流程：Agent（如 WorkBuddy）生成网页 → 拖进花生壳 Drop → 认领 → 公网可访问

## 价格 / 限制
- 当前**免费**、长期保存
- 静态托管边界：不能运行 Node.js、Python、数据库服务（动态项目需用 [[花生壳 HSK-CLI]] 内网穿透）
