# WorkBuddy

## 定位
在本库多篇文章中出现的腾讯系 AI Agent 工具：能一句话生成完整网页、构建应用、调用各类发布/后端能力，是 Agent 工作流的典型代表。

## 关键能力（来自本批来源的交叉观察）
- 一句话生成完整静态网页（如 NAS 服务导航页、含动画的复杂前端），保存到本地
- 能启动本地真实服务（如 Express 服务），并可调用 [[花生壳 HSK-CLI]] 把本地端口发布到公网（Agent 会自动检索、安装工具）
- 已接入 [[腾讯云 CloudBase PostgreSQL]] 作为默认后端数据库：用户连接后直接利用 CloudBase 做应用的数据库和后端
- 发布链路：可配花生壳 Drop / HSK-CLI，侧边栏会弹出花生壳认领界面

## 价格 / 限制
- 收费模式未在本批来源说明（知识空白）
- 不同 Agent 工具的发布能力不一致，用户有多个免费发布渠道可选
