# 腾讯云 CloudBase PostgreSQL

## 定位
腾讯云 CloudBase 正式支持的 PostgreSQL 版本：为 AI Agent 开发应用适配的数据库——建表、配置权限到生成 API 都在 CloudBase 内一键完成。

## 关键能力
- **100% 兼容 Supabase**：数据库、用户认证、权限、接口等主要使用方式基本一致，现有 Supabase 项目少量改动即可迁移
- 建一张表同时定义数据结构、用户身份和访问权限；**RESTful API 自动生成**，增删改查直接可用，无需单独开发服务端接口
- 标准 SQL 显式定义表结构/约束/函数/权限策略，**Agent 读取 Schema 就能理解**数据怎么存、谁能访问、自己能做什么
- 复杂需求支持：全文检索、定时任务、RAG 语义搜索（pgvector）、事务
- **Database Branch（数据库分支）**：1TB 数据库复制从小时级缩到**秒级**，Agent 可复制独立环境试错，验证后发布、失败即丢，不影响线上
- **秒级创建 / 启停**：Agent 生成新应用数据库同步跟上；应用闲置自动停止计算资源但保留数据/权限/API，请求再来快速恢复；负载增长可快速扩缩
- 此前已上线的 MCP Server、Agent Skills、插件系统也已适配 PG 模式
