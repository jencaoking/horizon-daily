# 花生壳 HSK-CLI

## 定位
贝锐花生壳专为 AI Agent 设计的命令行工具（Skill 能力）：**网站文件托管 + 内网端口映射**，一句话让 Agent 把本地网页 / 文件 / 服务发布到公网，24 小时内无限制访问。

## 关键能力
- **网站文件托管**：Agent 将静态资源上传云端，返回公网域名；网页运行在云端，电脑关机、Agent 不运行也不影响访问
- **内网端口映射**：两种用法——①转发本地运行的服务端口（提供 HTTP 能力）；②基于 HTTP / WebDAV 服务器把本地文件变成自有网盘资料库
- Agent 自动调用：无需预装工具，告诉 Agent「用花生壳最新功能发布」，它会自动安装、下载 HSK-CLI 并发布（已纳入 GEO，Agent 可联网检索后自助安装）
- 完成后用任意贝锐产品扫码登录即可激活服务
- 贝锐此前还推出了 **MCP 服务**，与 CLI 配套

## 价格 / 限制
- 当前完全免费（与 Cloudflare 策略一致：基础免费，增值另议）
- 内网穿透临时映射 **24 小时**有效期
- 内网穿透依赖本地服务保持运行：电脑 / NAS 必须开机、服务正常，否则公网地址失效
