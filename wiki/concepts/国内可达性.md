# 国内可达性

## 定义
国外云服务 / 平台在中国大陆的实际可访问性——受网络环境、域名备案、微信分享限制等影响。它是国内开发者和用户在选型时反复出现的胜负手。

## 为什么在 AI Agent 时代重要
- **分享工具的生死线**：Agent 生成的网页、报告要发给普通人（甲方、同事），"链接交到别人手里好不好用"才决定价值。国外服务（如 workers.dev）国内打不开，再好的工具也白搭
- 案例对比：
  - [[Cloudflare Drop]] 部署到 workers.dev → 国内无法访问、微信分享受限
  - [[花生壳 Drop]] 域名已在国内备案 → 直接访问、微信内分享无限制
  - [[Void.cloud]] 基于 Cloudflare 全球边缘 → 国内无需翻墙即可稳定访问
- 决策启示：同类免费工具，**国内可用性往往比功能更强更能决定选择**；国产厂商（花生壳、华为云、腾讯云）正基于此切入 Agent 基础设施市场

## 相关工具 / 案例
- [[Cloudflare Drop]] / [[Cloudflare Tunnel]] — 功能好但国内访问受限
- [[花生壳 Drop]] / [[花生壳 HSK-CLI]] — 已备案域名，国内友好
