# 内网穿透

## 定义
把位于内网 / 本地的服务、端口、文件，通过公网节点"打洞"映射为可访问的公网地址——不需要公网 IP、不需要搭服务器中转。本质是隧道（Tunnel）技术。

## 为什么在 AI Agent 时代重要
- **发布链路自动化**：过去穿透要自己搭 VPS 中转、手动装客户端、接节点；现在由 Agent 自动调用 CLI / MCP 完成（如 [[花生壳 HSK-CLI]]），用户只下指令
- Agent 生成本地服务 / 网页后，穿透是把成果"接到公网"的最后一公里；本地服务需要给别人看（同事、甲方、团队测试）时尤其关键
- 与 [[静态托管]] 形成互补：静态文件托管走云端（关机不影响），运行中的服务靠穿透（依赖本地在线）

## 相关工具 / 案例
- [[花生壳 HSK-CLI]] — 内网穿透 + 静态托管双能力，免费，24h 临时映射，需本地在线
- [[Cloudflare Tunnel]] — cloudflared 一键穿透，trycloudflare.com 临时地址，国内不稳定
- [[花生壳 Drop]] / [[Cloudflare Drop]] — 属于静态托管（不是穿透），见 [[静态托管]]
- 传统方式：VPS 中转 + 手动客户端（已被厂家节点 + Agent 部署取代）

## 关键限制
- 内网穿透映射有有效期（花生壳 24h、Cloudflare 临时）
- 本地服务停止 → 公网地址失效
- 移动端访问 / 稳定性可能有兼容问题（见 [[Cloudflare Tunnel]] 实测）
