# 静态托管

## 定义
把 HTML、CSS、JavaScript、图片等静态文件发布到公网，生成一个可访问的链接。不需要服务器持续运行后端进程，上传即生效。

## 为什么在 AI Agent 时代重要
- **Agent 产物的标准出口**：Agent 生成的周报、竞品分析、会议纪要、项目进度页都是 HTML——静态托管让"做出来的东西"一键变成别人能打开的网页
- 典型工作流：Agent 生成完整网页 → 拖进托管平台 → 认领链接 → 微信 / 邮件甩给对方，24 小时保真
- 网页托管在云端，**电脑关机、Agent 不运行也不影响访问**（与 [[内网穿透]] 相反）

## 相关工具 / 案例
- [[Cloudflare Drop]] — 免费，部署到 workers.dev，但国内打不开
- [[花生壳 Drop]] — 免费、长期保存、域名已备案国内可访问、支持单 html 文件
- [[Void.cloud]] — 超越静态托管：静态 + 后端 + 数据库全栈一键部署
- [[花生壳 HSK-CLI]] — 网站文件托管（静态资源上传云端）

## 边界
- 静态托管不能运行 Node.js、Python、数据库服务——需要运行时的项目走 [[内网穿透]] 或全栈平台（[[Void.cloud]]）
